最近去电影院看了《流浪地球》，电影总体给7分，设定、效果等确实不错，但表演和剧情稍显单薄了点。很多年前就看过了大刘所有的作品，所以这部电影对我来说也算是情怀片吧。

在豆瓣上记录的时候，提示我已经看了221部科幻片了，科幻可以说是我最喜欢的剧情种类，无论是小说还是影视剧，其中的波澜壮阔、脑洞大开、硬核烧脑是我最享受的体验。

下面就顺着豆瓣的记录，结合自己的回忆，列一下我喜欢的科幻电影。

# 1. [2001太空漫游](https://movie.douban.com/subject/1292226/)

![](https://image.deepnomind.com/blog/image/13019db49790371befa2905c255fdcb4)

这部电影可以说是科幻电影的一座丰碑。看过这部电影的十几年后，我还是在每次听到“蓝色多瑙河”的音乐声就会在脑海里浮现出宇宙飞船在浩瀚的宇宙中漂浮游荡的画面。  
这部电影之后，还有一部续集《2010》，并且小说还有第三部《3001》。从个人体验来说，小说比电影要精彩很多。

# 2. [盗梦空间](https://movie.douban.com/subject/3541415/)

![](https://image.deepnomind.com/blog/image/3792bbb2eaaf7ee1c7c9da3010a6571d)

设定脑洞巨大，各种细节层层铺垫，又能够抽丝拨茧把所有坑都填上，非常烧脑的一部作品。剧中旋转的陀螺这个梗在后来被很多影片致敬，包括《流浪地球》。

# 3. [星际穿越](https://movie.douban.com/subject/1889243/)

![](https://image.deepnomind.com/blog/image/83a7bb3e19371ef7bb4a2d971bb6cc68)

剧中的科学原理为人津津乐道，被反复讨论，电影中构造的虫洞成为了科幻中的经典。看完这部影片，我对高维空间的生活充满了想象，也希望今后能看到导演能够拍摄续集，把这部分内容进一步展开。

另外说一句，《盗梦空间》和《星际穿越》都是克里斯托弗·诺兰导演的，他还导演了《敦刻尔克》、《蝙蝠侠：黑暗骑士》三部曲、《记忆碎片》等牛片。

# 4. [攻壳机动队](https://movie.douban.com/subject/1291936/)

![](https://image.deepnomind.com/blog/image/d95cf47ce5ddc4792714a415307cc1a2)

整个系列包含了多部系列动画及动画电影，赛博朋克的巅峰之作，全片充满了各种符号、意象，不熟悉赛博朋克文化的人看起来会比较吃力。讨论了很多深奥的哲学命题：科技意味着什么？什么是人？什么是意识？

# 5. [银翼杀手](https://movie.douban.com/subject/1291839/)

![](https://image.deepnomind.com/blog/image/abb72639b4c4390da0a28dd4c1a050cf)

同样是赛博朋克的代表作，包含了多部系列电影，我始终相信，剧中的讨论的问题终有一天会成为现实问题，到那时我们将怎样面对和我们一样的另一种人类？

# 6. [黑客帝国](https://movie.douban.com/subject/1291843/)

![](https://image.deepnomind.com/blog/image/f37bfdd580ac9628722188d8bde9da03)

普遍认为《黑客帝国》的设定直接继承/脱胎于《神经漫游者》、《攻壳机动队》。影片构造了一个完整的世界观，也是在科幻圈子非常流行的一种设定，就是整个世界都是计算机模拟的。Neo躲子弹的场景已经成为经典，被无数影片致敬。

# 7. [阿凡达](https://movie.douban.com/subject/1652587/)

![](https://image.deepnomind.com/blog/image/e5f0a6a2434fb0870a9347f4b1d021e2)

设定其实没有什么新奇的地方，但画面非常唯美壮阔，用丰富的细节构建了一个想象中的美丽世界。这部电影宣告了3D时代的来临。

# 8. [火星救援](https://movie.douban.com/subject/25864085/)

![](https://image.deepnomind.com/blog/image/12458d3337726f4980aee87546188c53)

太空版鲁滨逊漂流记，引来一堆人在网上讨论技术上的可能性，传统硬核科幻。

# 9. [这个男人来自地球](https://movie.douban.com/subject/2300586/)

![](https://image.deepnomind.com/blog/image/1ef535c863c1aa52daf34637bd17b11b)

个人非常喜欢的一部影片，极简的场景，就靠对话推动情节发展，考虑到这部影片的投资才1万美元，绝对可以算是最牛\*的电影之一了。影片场景虽然极度简单，但讨论的都是宏大的问题，关于时间与空间的思考，人类存在与现实的关系以及宗教的本质到底是什么。

# 10. [银河系漫游指南](https://movie.douban.com/subject/1292267/)

![](https://image.deepnomind.com/blog/image/e2f9ae34589d6b28f696a25dd4063666)

大部分科幻电影都是要拯救地球，这部片子一上来就把地球给强拆了，大快人心啊！  
这部片子给我们提供了大量的梗，还告诉了我们生命、宇宙以及任何事情的终极答案：42。

最后，[《星球大战》](https://movie.douban.com/subject/1293838/)系列，不用说了，已经成为美国文化的符号之一，准宗教一样的存在。

科幻给我们的意义就在于，当我们埋头奋斗的时候，可以时不时有机会仰望一下天空。
